# 👤 Profile Card UI/UX Design

A simple and modern **Profile Card UI/UX Design** created using **HTML5 and CSS3**. The project demonstrates the use of CSS Flexbox, styling, icons, buttons, and a profile image to create a professional profile card.

## 📌 Project Overview

This project contains a profile card design with a profile image, developer information, social media icons, action buttons, and engagement statistics.

The main design is titled **"Profile Card UI UX Design"** and includes information about a Website Developer from **Dezyne Ecole College**. 

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- Font Awesome
- Google-style UI concepts
- Image Styling

## ✨ Features

- 👤 Profile card design
- 🎨 Modern UI/UX layout
- 📱 Profile image
- 💻 Developer information
- 🎓 College and course information
- 🔗 Social media icons
- ❤️ Like statistics
- 💬 Comment statistics
- 📤 Share statistics
- 🔘 Subscribe button
- 💬 Message button
- 🌑 Shadow and rounded-corner design

## 🧩 Profile Information

The profile card displays:

- **Website Developer**
- **Dezyne Ecole College**
- **BCA 1st Year**

It also includes Facebook, Instagram, LinkedIn, GitHub, and Behance icons.
